# Security Policy

## Supported Versions

The project currently provides security updates for the latest version and the current default branch. Older versions may no longer receive fixes unless explicitly listed below.

| Version | Supported |
| ------- | --------- |
| latest | :white_check_mark: |
| previous stable release | :white_check_mark: |
| older releases | :x: |

If this project introduces numbered releases, update this table to reflect the currently supported release line.

## Reporting a Vulnerability

Please do not open a public GitHub issue for any security vulnerability.

Instead, report it privately by contacting the maintainer directly or by using GitHub's private security advisory flow if it has been enabled for this repository.

Include the following in your report:

- Affected version or branch
- A clear description of the vulnerability
- Steps to reproduce the issue
- Any proof of concept or relevant logs
- Your preferred contact method for follow-up

We aim to acknowledge valid reports within 5 business days and will work with you on a coordinated disclosure. Once a fix is ready, we will publish the advisory and credit the reporter if appropriate.
